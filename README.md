# المنظومة الرقمية الموحدة لشركة النصبان للحراسات الأمنية (v2.0)
## دليل البنية الهندسية، التشغيل والامتثال الأمني (PDPL Compliance & Production Guide)

---

### 🌟 نظرة عامة
تم بناء هذه المنظومة كبديل آمن، مؤسسي، ومطابق 100% للأنظمة السعودية لمعالجة كافة الثغرات والعيوب التقنية والتشريعية التي تم رصدها في الموقع السابق (`https://hrannasban.com/`).

تعتمد المنظومة على بنية هندسية حديثة تجمع بين:
1. **واجهة مستخدم تفاعلية متطورة (`index.html`)**: تدعم منصة التوظيف، العقود الرقمية، منصة مساندة، بوابة الموظف الذاتية، ولوحة إدارة الموارد البشرية.
2. **خادم خلفي آمن ومستقل (`server.js`)**: مبني بمكتبات Node.js القياسية الحديثة مع محرك قاعدة بيانات محلي `node:sqlite` فائق السرعة، خالي من أي تبعيات هشة أو مخاطر إمداد برمجيات (Zero Supply-Chain Risks).
3. **محرك الامتثال لنظام حماية البيانات الشخصية السعودي (PDPL Audit Engine)**: توثيق وتشفير كل استعلام أو وصول لبيانات المواطنين الحساسة في سجل تدقيق غير قابل للتلاعب.
4. **حزم النشر والتشغيل السحابي (`Dockerfile` & `docker-compose.yml` & `nginx.conf`)**: جاهزة للنشر الفوري داخل المملكة على أي خادم سحابي أو محلي.

### 🛡️ أبرز الإصلاحات الأمنية والتشريعية المطبقة

| المعيار | ما كان موجوداً في الموقع السابق | الحل المطبق في المنظومة الجديدة (v2.0) |
| :--- | :--- | :--- |
| **رموز التحقق الوظيفية** | رموز PIN مكشوفة في كود JavaScript بالمتصفح | إلغاء الرموز المكشوفة؛ التحقق يتم بخوادم مشفرة مع حماية الجلسات بـ JWT. |
| **الهوية الوطنية** | إدخال نصوص عشوائية بدون تدقيق رياضي | فحص صارم بخوارزمية **لُهن (Luhn)** والتأكد من بداية الهوية بـ 1 أو 2. |
| **الحساب البنكي (IBAN)** | لا يوجد أي تدقيق على الآيبان | تدقيق معياري دولي طبقاً لـ **ISO 7064 Mod 97-10** والتعرف على البنك السعودي تلقائياً. |
| **التوقيع الإلكتروني** | مجرد كتابة اسم بخط عربي مزخرف | توقيع موثق بتجزئة رقمية مشفرة **SHA-256** مع معرفات نفاذ الوطنية وتوقيت معتمد. |
| **هجمات التخمين (Brute Force)** | لا يوجد أي قيود على عدد محاولات الدخول | تفعيل **Rate Limiting** ومكافحة البوتات عبر كابتشا حسابية ذكية وحظر الـ IP تلقائياً. |
| **تسريب مسارات الخادم** | إرجاع مسارات داخلية `/app/dist` في أخطاء 500 | منع تسريب أي Stack Traces وإرجاع ردود JSON آمنة وموحدة. |
| **الامتثال لنظام PDPL** | حفظ بيانات المواطنين على خوادم أجنبية في فرنسا | حفظ محلي آمن داخل المملكة مع سجل تدقيق تفصيلي **Audit Logger** لكل استعلام. |

### 🚀 تشغيل المنظومة واختبارها

#### 1. التشغيل المحلي الفوري (Local Run):
```bash
# تشغيل الخادم الرئيسي
node server.js
```
*يفتح الخادم على الرابط:* `http://localhost:3000`

#### 2. تشغيل الفحص الأوتوماتيكي الشامل (Automated Security Audit):
```bash
node test_system.js
```
*يقوم السكريبت باختبار 24 معيار أمان تلقائياً (التشفير، الترويسات، Rate Limiting، نفاذ، العقود، وسجلات التدقيق).*

#### 3. التشغيل السحابي عبر Docker & Nginx:
```bash
docker compose up -d --build
```

### 📋 توثيق أهم مسارات الـ REST API

* `POST /api/auth/login`: مصادقة مسؤولي الموارد البشرية وإصدار رمز JWT.
* `POST /api/auth/employee-login`: دخول الموظف برقم الهوية وكلمة المرور مع كابتشا.
* `POST /api/nafath/initiate`: بدء طلب توثيق نفاذ وإصدار رمز عشوائي من رقمين.
* `POST /api/nafath/verify`: التحقق من تأكيد المعاملة في تطبيق نفاذ.
* `POST /api/contracts/sign`: تسجيل وتوقيع عقد العمل رقمياً وتوليد بصمة SHA-256.
* `GET /api/employees/pay-slips`: استرجاع مسيرات الرواتب بخصومات التأمينات والبدلات.
* `GET /api/audit/logs`: استعراض سجلات التدقيق الأمني لمسؤولي الامتثال (مراقب بـ PDPL).
* `GET /api/health`: نقطة فحص الجاهزية التشغيلية وترويسات الأمان.
